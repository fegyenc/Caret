# Getting started with Caret

Caret is a calm Markdown editor for Windows. It also turns Word, Excel, PowerPoint, PDF and Outlook emails into clean Markdown. Everything happens on your PC: no account, no cloud, no AI.

## Write

- **New Note** (top of the sidebar) starts a note. The buttons **View**, **Code** and **Split** (top right) switch between a formatted page, plain Markdown, and both side by side.
- Several documents open as *tabs*. `Ctrl+W` closes one, `Ctrl+Tab` moves between them, and `Ctrl+K` jumps to any file in your folder.
- **Library > Templates** keeps your templates. **Add starter templates** brings a set in the language of the interface: letters, a CV, a report, minutes, a speech and a presentation.
- Spelling is checked with Windows' own checker, offline. Right-click an underlined word for suggestions.
- Your work is saved as you go (Settings > General > Auto-save) and recovered after a crash.
- Where is the file? Right-click a file in **Recent**, in **Favorites** or on the start page, or use the **File** menu for the open file: **Reveal in File Explorer** opens its folder with the file selected, and **Copy as Path** and **Copy file link** copy where it is.

## Convert

**Documents and scans** (sidebar) turns Word, Excel, PowerPoint, PDF and CSV files into Markdown, and **Outlook emails** turns a whole email conversation into one clean file. See the topic *Convert documents and emails*.

## Review and speak

- **Review** adds comments, compares two versions of a file and lets you accept or reject each change. See *Review: comments and changes*.
- **Speech marks** help you prepare a talk: pauses, pace, emphasis, timing, a teleprompter. See *Speech marks*.

## Share

**File** > **Export** writes HTML, PDF and plain text, and a real **Word Document (.docx)** with headings, lists, tables, pictures, footnotes, equations, and comments and tracked changes from a review. See *Export to Word*. **Markdown with pictures (.zip)** puts the note and its pictures in one zip, with the picture links made relative in the copy, so that you can send it to someone and the pictures go with it (Windows opens a zip with no extra program). Pictures on the web (http links) are not copied: the person who receives the zip needs to be online to see them. The note and its file are not changed. **Collect pictures next to this note** (File menu) goes one step further for a note you will keep: it copies the pictures the note links to from other places into an images folder beside it and makes the links relative (Ctrl+Z puts the old links back, but the copied files stay in the images folder), so that a folder copy of the note is complete. New installs already paste pictures next to the note; see *Settings*.

In the PDF options you can add a watermark (DRAFT, CONFIDENTIAL, or any text you type), a header text, a footer text and page numbers (1 / 3). They are printed on every page and are added only for the export: the note is not changed. A header, a footer or page numbers of your own take the place of the browser's header and footer (date, title and address).

## Where things are

- **Settings** (the gear at the top right, or `Ctrl+,`): language, colours, layout, spelling, review and more. The search box finds a setting by its name.
- **Help** (this menu) has these topics, a link to report a problem, and the About page.
- Caret keeps its own settings and copies of unsaved work in its own folder. It never moves or changes your documents unless you save them.

## Something is wrong, or missing?

Choose **Help > Report a problem**. It opens the project page on GitHub, where you can describe what happened or ask for something. Caret never sends anything by itself.
